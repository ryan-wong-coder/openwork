# Mainstream original exercise media: root batch

Seven exact exercises have independently generated illustrations and videos:
`0025`, `0662`, `0032`, `0027`, `3593`, `0085`, and `1760`.
The image prompts and identity reference are recorded in each `*-image.json`;
the actual official LibTV model, node, task, prompt and settings are preserved
in `*-video-generation.json`. Workspace-bound selected files are in
`apps/app/public/zeno/fitness/`, with complete hashes in `provenance.json`.

Built-in Image Gen supplied new illustrations from the existing Zeno mascot
identity only. Official LibTV CLI created and generated each video; its formal
download command retrieved the current batch. The earliest bench-press output
was retrieved from the exact CDN asset returned by that same CLI before the
download subcommand was discovered. No restricted upstream exercise media was
used as input or copied. No generation or vendor dependency is needed at runtime.

Each final clip was actually viewed as eight one-second contact frames and
decoded in full. The first conventional deadlift clipped the head when upright;
it was withdrawn before runtime registration and replaced by a wider second
generation. The first Romanian deadlift did not clearly distinguish a hip
hinge; it was rejected. The second uses a side-on hinge reference. Its selected
1.5–7.5-second interval, slowed 4/3, contains one complete repetition starting
and ending upright. Its poster is the actual first selected frame. Rejected
generation metadata and contact sheets remain explicitly identified as attempt
1; they are not shipped as runtime assets. CLI name collisions refused creation
before a generation submission and were corrected without resubmitting a task.

General movement semantics were checked against primary written guidance:
[barbell Romanian deadlift](https://www.nasm.org/resource-center/exercise-library/romanian-deadlift-barbell)
and [goblet squat](https://www.nasm.org/resource-center/blog/training/how-to-perform-goblet-squats).
No source photographs or diagrams were used. These are stylized movement
illustrations; professional human technique or clinical validation is not claimed.
