# 泽诺 Zeno 1.1.2

- 修复同时打开多个网页时，电脑授权页无法点击同意连接的问题。
- 为 32 个常用动作补齐原创海报和演示视频，动作详情显示正背肌群图。
- 训练中可直接查看动作详情，支持播放控制和减少动态效果。

Windows、Linux、macOS，分别提供 x64 与 arm64 安装包。

macOS 的 self-signed 包使用持久自签证书，未取得 Apple 公证；首次打开可能需要系统确认。后续更新必须保持同一签名身份。Windows 未签安装包可能显示未知发布者。

各架构更新目录与 SHA-256/SHA-512 校验见 zeno-release.json。
