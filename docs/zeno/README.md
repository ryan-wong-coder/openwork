## 本次实现

首页使用透明水獭、真实输入器和三个可编辑的任务起点；聊天、侧栏、设置与资料库采用平面背景、细分隔和少量品牌色。说明保留在帮助与详情中。欢迎和草稿姿态使用独立资源，不把装饰姿态冒充任务进度。

默认个人版本停止官方账号恢复、Den/Connect 同步、官方目录推荐、免费推理、遥测、托管心跳与官方自动更新。用户自行安装的技能、插件、MCP、模型网关与其服务授权继续保留。已有受管发行明确要求的登录策略只属于显式旧配置，不随改名绕过；已有凭据和用户数据不被清除。

网关的客户端就绪状态与管理配置分开读取。没有管理权限的自部署 Web 显示真实只读状态，管理地址、密钥和模型仍需 host-token。普通会话无需读取或获得这个管理凭据。

`zenoInterface` 已在功能注册表中声明，默认关闭；个人版本通过本地配置启用。视觉样式以该状态门控，旧连接模式保留原界面。API/SDK 与 Helm 派生文件随功能注册表一同生成。

实现依据 `DESIGN.md` 的 S1、V1、V7：保持工作界面结构、13px 正文和不超过 20px 的标题，移除额外玻璃层、渐变与重复外壳。参考图中的展示密度与实际产品的明确差异记录在验收报告中。
