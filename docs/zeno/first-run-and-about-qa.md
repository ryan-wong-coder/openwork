# 首次网关设置与关于页验收

日期：2026-10-16。final result: passed。

## 实际行为

未配置网关的个人版本会直接显示 ModelHelm 密钥输入页。填写后只向现有受保护接口提交 `apiKey`，保留部署者设置的地址、模型和生成参数；成功时，有工作区的安装会确认其实际运行的 V1/V2 引擎目录包含已连接的对话模型，再进入首页。没有工作区时进入原有新建任务 / 创建工作区流程，不再对不存在的工作区模型目录反复重试。

已经配置的安装直接进入应用，不重复索取密钥。读取失败不等于未配置；无管理权限的 Web 只提示部署者完成配置。稍后设置只跳过本次页面访问，不持久化“已配置”标记。恢复可见窗口时，即使连接层重新创建客户端，同一服务、token 和运行代次仍保留输入、跳过及待应用状态；实际切换连接时清空旧输入并忽略旧请求。

密钥使用现有 `SecretField`，默认遮蔽，提交即清空；不进入聊天、React 文本状态、浏览器持久化或静态包。服务器返回的原始错误不直接渲染。无效密钥与 host 管理权限失效分开处理；保存后尚未应用、运行目录未确认或刷新失败均保留重新检查操作。

新增设置中的独立 `/settings/about` 页，包含生日祝福、用户明确指定的署名与“基于 OpenWork 改造”。许可详情保留上游 MIT 原文和适用范围；不自动连接官方服务，也不添加官方登录。全局入口和工作区入口均可达，关闭功能或显式旧 connected 配置时回到通用设置。

## Headless 实测

在独立临时配置、环境存储、运行数据库和工作目录中启动真实应用、服务器及 OpenCode 引擎。测试用上游仅实现确定的 `/models` 响应，使用合成凭据；没有读取或覆盖使用者的真实网关配置，也没有请求真实 ModelHelm 额度。

浏览器默认只带客户端凭据，实测不能读取或修改 host 管理配置。需要验证桌面首设权限时，仅对这个临时服务的 `/gateway/*` 请求附加它自己的 host-token，模拟桌面已有的管理授权；没有向公开 bundle 或通用请求头注入密钥。这属于 headless API 权限验证，不是原生窗口或打包安装验证。

实际完成：空密钥状态、错误密钥后重新填写、正确凭据保存并回首页、浏览器存储无提交密钥、已有配置重载后不再显示引导。模拟 `visibilitychange` 恢复事件后，未发送输入仍保留；点击稍后设置后，同样事件不重新弹出。删除的仅为临时测试工作区；空注册表重新填写后正常回到原有空工作区首页，无重新检查死循环。

从真实设置导航进入关于页，确认归属、两段祝福、署名、实际版本和折叠许可。390px 中展开许可后的 document scrollWidth 仍为 390px，没有横向溢出。许可和关于页没有官方外链、嵌入或自动请求。
