实现方另留存了默认自部署 Web 的 [冷启动网络记录](verification/selfhost-network.json)、[真实对话网络记录](verification/selfhost-chat-network.json) 与 [鉴权边界检查](verification/selfhost-auth-boundary.json)。前两次记录分别观察 1025 / 141 个请求，未观察到官方请求或 Runtime exception；这只覆盖记录所述场景。鉴权检查确认：无客户端凭据读取状态返回 401，有客户端凭据读取状态返回 200 且 `no-store`，仅客户端凭据读取敏感管理配置仍返回 401。

归档共 36 个验收文件，只包含本报告引用的截图/记录及上述三份自部署检查。未归档 token、完整 API 密钥、cookie 或请求头；配置截图中的末四位只是密钥识别提示，不能用于认证，仍不应据此推断、重建或分享完整密钥。

## 限制与后续精修

- 没有独立的暗色、窄屏、资料库或真实聊天概念，因此这些状态依据同套视觉方向及 `DESIGN.md` 验收，而不是声称还原了不存在的设计稿。

- 已检查常用尺寸与键盘浮层；尚未完成所有页面的 200% 字体缩放、完整读屏路径或所有第三方 OAuth 服务实测。这些未观察到的状态不作为已通过事项。
